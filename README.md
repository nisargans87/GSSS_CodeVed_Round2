## 📌 Project Overview

This project is a custom web implementation of the classic Tic-Tac-Toe game with a unique technical twist. Instead of placing symbols in a regular board, participants are challenged to predict the output of Java code snippets. Each correct prediction allows the user to place their mark on the board, while a wrong answer or timeout gives the computer an opportunity to respond.

The application is designed for an event environment, where competitive participation, quick thinking, and technical accuracy matter. It transforms a familiar game into an engaging academic and technical challenge suitable for fest-based technical events.

## 🧠 Gameplay Mechanics

The project follows a game-style technical challenge format:

1. A participant enters a name and starts the game.
2. A Java snippet is displayed to the player.
3. The participant predicts the program output.
4. If the answer is correct, the player earns a move and marks the board.
5. If the answer is incorrect or the timer ends, the computer takes the move.
6. Each correct move contributes to the participant’s total marks.
7. Results are displayed after completion for evaluation and ranking.

This turns traditional Tic-Tac-Toe into a competitive technical challenge focused on debugging, logic reasoning, and output prediction.
